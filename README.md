# Orchestration

Personal Python scripts for local LLM orchestration, terminal helpers,
and Linux desktop experimentation.

## Ubuntu Wayland game development

- Guide: [ubuntu_wayland_game_dev.md](ubuntu_wayland_game_dev.md)
- Checker: [wayland_game_dev_check.py](wayland_game_dev_check.py)

Run:

```bash
python wayland_game_dev_check.py
```

The checker reports desktop session variables, common game-development
tools, native library availability, and graphics runtime diagnostics.
